# 商业化边界：随机付费、时间压力与玩家公平

商业化会改变玩家的时间、选择和竞争条件。评审不能只问收入是否提高，还要检查玩家能否理解价格和概率、能否拒绝、损失是否有限，以及脆弱群体是否承担额外风险。

## 1. 透明度

明确展示真实价格、概率、保底、继承、过期和替代路径。多层货币不能用于隐藏实际成本；随机商品应记录完整条件概率、累计概率和最高成本。

界面中的“价值”与“折扣”要有可验证参照，不能用虚构原价或不可单独购买的填充物制造夸张折扣。

## 2. 随机付费

随机性会让支付相同金额的玩家得到不同结果。除期望值外，必须评估 P50、P90、最坏成本、重复物和退出路径。保底限制尾部，但不会自动消除公平、冲动消费和概率理解问题。

涉及付费时，概率状态、计数、迁移和退款必须可审计。不要根据玩家付费能力或近期行为秘密改变条件概率。

## 3. 时间压力

限时内容可以组织活动节奏，但虚假倒计时、反复返场的“最后机会”和惩罚性连续登录属于不必要压力。玩家应知道错过什么、是否返场、能否补领以及退出成本。

活动时间应足以覆盖不同作息，并提供进度预估。临近结束时才发现理论上无法完成，会造成强迫性补购。

## 4. 付费公平

公平取决于产品承诺。竞技项目需要检查付费是否直接决定胜负、匹配是否隔离资产差异、免费玩家是否保有完整反制。合作和单人项目也应避免先制造痛点再出售解决方案。

便利付费若逐步把基础操作变得不便，同样会侵蚀体验。免费路径应能完整理解和使用核心系统。

## 5. 护栏指标

商业化实验除收入外，还应观察退款、投诉、后悔反馈、购买后流失、超额消费分布、未成年人风险和长期留存。预算提醒、冷静期、消费记录和便捷退款能够提高可控性。

统计购买率时区分主动需求、强门槛和误触。短期收入增加可能伴随长期信任损失。

## 6. 伦理预检

评审时逐项询问：玩家是否理解；是否有真实替代；拒绝后能否继续正常游戏；是否利用认知混淆；损失是否有上限；规则改变时资产如何保护；是否为未成年人和高风险消费提供额外保护。

## 7. 风险分级

低风险包括价格明确的外观和永久内容；中风险包括周期订阅、随机但有清晰上限的商品；高风险包括无限随机、复杂货币换算、临近截止的高额补购和直接影响竞技胜负的付费能力。风险越高，越需要上限、提醒、审计和人工复核。

## 8. 评审记录

商业化方案应保留目标、玩家价值、免费路径、最大成本、退出方式、未成年人措施、退款、护栏指标和负责人。伦理评审不是一句“玩家自愿”，而是检查玩家是否拥有充分信息和真实拒绝权。

## 发布前检查

- [ ] 真实价格和概率是否清楚？
- [ ] 随机付费是否有有限尾部和退出路径？
- [ ] 限时是否来自真实内容周期？
- [ ] 付费是否取消了非付费玩家的反制？
- [ ] 是否设置收入之外的玩家保护指标？
