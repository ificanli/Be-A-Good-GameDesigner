# 游戏设计逻辑

一个持续积累游戏设计干货的公开知识库，目标是发布为 GitHub Pages 博客。

## 在线预览

进入仓库的 **Settings → Pages**，选择 `GitHub Actions` 部署。工作流会发布 `docs/` 目录中的静态站点。

## 内容方向

- 基础理论、玩法与机制
- 战斗、成长、装备、技能与数值经济
- 关卡、叙事、玩家体验与 UX
- 原型测试、数据运营、多人社交与 AI
- 品类专题、案例拆解、资料卡和可复用模板

## 资料原则

外部资料只做链接、必要引用、结构化摘要和交叉核验；不整篇转载。文章会区分原始来源、研究笔记、原创方法论和待验证观点。

## 本地预览

无需构建工具。在项目目录执行：

```bash
python -m http.server 8000 -d docs
```

然后打开 `http://localhost:8000`。

## 目录

- `00_索引与规范/`：知识库规则与发布规划
- `03_系统设计/`：成长、装备、技能
- `04_战斗设计/`：战斗数值
- `05_数值与经济/`：教程凝练与完整数值框架
- `99_资料来源/`：来源与资料卡
- `docs/`：GitHub Pages 静态发布目录
