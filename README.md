# 游戏设计逻辑

公开游戏设计知识库。目前根目录只保留两个正式内容系列，其余原始资料、维护规范、旧分类和网站程序统一收纳在 `内部资料/`。

## 正式系列

### 游戏数值设计方法

路径：

```text
游戏数值设计方法/
```

从基础建模、战斗数值、成长养成和经济概率，延伸到验证复盘、多人平衡、版本迁移、商业化边界与生产工具。

### 游戏立项脑暴

路径：

```text
游戏立项脑暴/
```

整理从立项目标、创意生成、机制筛选和竞品查重，到纸面推演、原型验证、试玩诊断与立项决策的完整流程。

## 内部资料

```text
内部资料/
├─ 规范/            # 收录、凝练、判断与发布规则
├─ 原始资料/        # 导入的原稿、项目文件、截图和电子资料
├─ 资料来源/        # 资料卡、来源索引与引用记录
├─ 知识库旧分类/    # 旧版 01—16 主题目录，保留供以后新系列提炼
├─ 网站/            # GitHub Pages 静态站点
├─ 工具/            # 脚本和验证工具
└─ 项目配置/        # 非正文项目文件
```

`内部资料/` 中的内容不会因为根目录重构而删除。原始资料是否公开仍按各自版权和发布规则处理。

## 在线网站

https://ificanli.github.io/Be-A-Good-GameDesigner/

网站只展示明确加入发布入口的正式系列。当前两套系列均支持选中文字进行批注，并导出 JSON 供后续修订。

## 本地预览

在仓库根目录执行：

```bash
python -m http.server 8000 -d "内部资料/网站/docs"
```

然后访问：

```text
http://localhost:8000
```
