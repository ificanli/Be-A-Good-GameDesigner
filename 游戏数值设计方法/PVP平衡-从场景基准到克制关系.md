# PVP 平衡：从场景基准到克制关系

PVP 平衡不要求所有角色在所有场景中表现相同。它要解决的是另一件事：优势是否有成立条件，对手是否能识别并反制，以及某个选择是否在主要场景中持续占优。

因此，平衡评审不能从“某角色胜率是多少”开始。更可靠的流程是先定义场景，再读取分层数据，接着判断克制关系和操作成本，最后沿影响路径修改最小根因。

## 1. 场景基准与异常验证

### 1.1 先写清楚要平衡的场景

同一角色在单挑、团队战、不同地图和不同分段中的价值不同。进入数据分析前，基准表至少要记录模式、地图、队伍规模、目标玩家熟练度、装备规则、先后手和目标对局时长。脱离场景的“角色胜率”不能直接指导修改。

场景定义也是后续决策的边界。若目标场景是高分段五人队在特定地图争夺窄口目标，那么低分段单排表现只能作为护栏，不能替代主要判断。反过来，若角色主要服务新手体验，高分段上限就不能单独决定削弱幅度。

### 1.2 用分层数据判断异常是否真实

胜率要和使用率、禁用率、镜像率、对局时长和投降率一起看，并按版本、段位、地图、位置、阵容、预组队和熟练度分层。高胜率可能来自角色过强，也可能来自只有熟练玩家使用；高使用率可能来自操作简单、免费开放或攻略传播。

至少比较新手使用者、稳定使用者和高熟练使用者的表现曲线。若新手曲线正常，高熟练曲线陡升，问题可能是上限或协同；若所有层级都高，才更像基础强度异常。这里不能把观察到的胜率直接写成证据之外的结论，尤其不能在缺少版本和样本条件时引用商业游戏案例证明普遍规律。

## 2. 克制结构与强度拆解

### 2.1 用克制矩阵确认优势结构

设角色或构筑 $i$ 对 $j$ 的胜率为 $W_{ij}$。克制矩阵用于回答四个问题：是否存在对多数对象都占优的全局解；是否存在几乎没有可胜对局的弱势选择；克制是否集中于阵容、地图或技能段；反制是通过操作、选角还是必须拥有特定资产完成。

矩阵的作用不是追求所有 $W_{ij}$ 都接近 50%。硬克制若在进入对局前就决定结果，会减少局内决策；更可取的克制通常改变风险和策略，但仍保留执行空间。若某个克制只在玩家拥有特定资产时才成立，还要把它视为养成和获取问题，而不只是战斗问题。

### 2.2 分开判断强度、易用性和上限

角色强度不能只用理想循环计算。评审应分别模拟理想操作、普通失误、网络延迟和关键技能未命中，并用实战保留率比较操作成本：

$$Retention=Performance_{normal}/Performance_{ideal}$$

理论上限相同但保留率不同，会形成显著的分段差异。保留率高的角色可能在低分段表现过强，保留率低但上限高的角色可能只在高熟练玩家手里压制环境。修改前要先说明异常来自基础属性、循环稳定性、技能命中门槛，还是团队协同。

## 3. 修改决策与诊断收口

### 3.1 沿传播路径修改最小根因

发现异常后，先沿传播路径定位：属性、技能、装备、地图资源、阵容协同或匹配。若问题来自地图目标，却只削弱角色倍率，其他地图可能同步变弱。若问题来自预组队协同，单排数据正常时也不应直接下调全部场景的伤害。

每次改动都要记录假设、目标分层、预期变化、护栏指标和回滚条件。优先修改能解释异常的最小变量，避免同时调整伤害、生存和冷却后无法归因。回归集至少覆盖主流与非主流构筑、克制双方、不同分段、地图和队伍结构；除胜率外，还要比较击杀时间、资源差、目标控制率和失败原因。

### 3.2 用诊断例串起决策链

某角色全服胜率 53%，不能直接判定过强。分层后发现：低分段 49%，高分段 57%；单排 51%，五人队 59%；特定地图 61%。继续检查发现，该角色的团队增益与地图窄口目标高度协同，问题主要来自团队场景，而非基础伤害。

这个案例的目标不是“把 53% 拉回 50%”，而是处理高分段五人队在特定地图的协同异常。处理方案应优先调整增益覆盖、地图交互或预组队场景，保留单排和低分段表现。若统一降低伤害，高分段团队问题可能仍在，其他场景却会变弱。

### 3.3 工作表收口

平衡工作表应包含角色版本参数、场景定义、使用者熟练度、胜率与使用率、克制矩阵、技能命中和循环表现、改动影响路径及回归结果。每个异常必须能追溯到配置版本和样本条件。

## 4. 发布检查与来源

### 4.1 发布前检查

- [ ] 是否定义了具体平衡场景？
- [ ] 胜率是否按熟练度和环境分层？
- [ ] 是否有克制矩阵和极端组合测试？
- [ ] 反制是否在局内可理解、可执行？
- [ ] 改动是否有传播路径和护栏指标？
