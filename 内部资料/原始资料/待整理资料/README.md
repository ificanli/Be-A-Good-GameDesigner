# 98 待整理资料

此目录用于暂存尚未完成阅读、核验和分类的原始资料。

## 目录用途

- `01_我的原创/`：个人文章、旧笔记、设计稿和复盘。
- `02_网页文章/`：网页存档、HTML、Markdown 和待读链接。
- `03_书籍与论文/`：PDF、电子书和论文。
- `04_视频与演讲/`：视频链接、字幕、演讲稿和听课笔记。
- `05_图片与图表/`：截图、示意图和参考图片。
- `06_表格与工具/`：公开性较明确的 Excel、计算表、脚本和原型工具。
- `07_项目资料/`：按项目整组保存的公式、配置、流程和拆解资料；默认禁止公开。
- `99_无法判断/`：暂时无法确定分类的内容。

## 使用方法

1. 原始资料直接放入对应目录，不需要预先改写。
2. 只有链接时，记录到 `02_网页文章/待读链接.md`。
3. 原始文件原则上不覆盖、不改名；整理成果另存到正式知识目录。
4. 可能错误或准备删除的重要内容进入 `00_索引与规范/待判断内容清单.md`。
5. 未确认版权的外部原文不复制到 `docs/`，也不发布到网站。

## 整理状态

可在文件名旁的资料登记表中使用：

- `待登记`
- `待阅读`
- `阅读中`
- `待判断`
- `已入库`
- `已归档`
