# 商品与礼包定价：价值锚点、折扣与购买上限

定价需要说明玩家获得了什么、替代路径是什么、节省多少时间，以及购买后如何改变成长节奏。折扣标签不能替代价值计算。

## 1. 建立免费基线

先计算目标玩家通过正常玩法获得商品内容所需的自然时间、有效游玩时间和机会成本。没有免费路径的独占内容，其价格来自内容、表达和稀缺定位，不能伪装成时间折算。

资源包可以从目标玩家可支配日产量建立初始锚点，但应扣除基础必需消耗。玩家每日获得 50,000 金币、固定消耗 35,000 时，可自由分配的基线是 15,000。

## 2. 混合礼包估值

混合礼包先逐项估算替代路径，再检查组合协同。若礼包同时提供突破材料和刚好配套的金币，其价值可能高于各项孤立相加。反之，大量玩家已毕业的填充物不应按标价足额计入。

统一战力或人民币换算适合内部比较，不代表玩家真实边际价值。相同资源在系统刚开放和毕业阶段的价值不同。

## 3. 折扣口径

折扣必须有真实可购买的参照价。区分常驻单品价、历史成交价、礼包拆分价和活动价。永久显示的“限时折扣”或从未按原价出售的虚高锚点会损害价格信任。

比较商品时使用实际支付、到账内容、使用限制、过期和漏领风险，而不只看“百分之几折”。

## 4. 购买上限与边际收益

重复购买会改变能力和库存。按购买次数计算每次后的边际收益、模块完成度和与免费路径的差距。

购买上限用于保护经济、内容寿命和玩家预算，不只是制造稀缺。若前几次性价比极高、后续骤降，应清楚展示，不让玩家依赖复杂换算才发现成本变化。

## 5. 商品结构

首购降低首次决策成本；月卡交换持续登录；战令交换周期参与；礼包提供明确资源组合；订阅承诺持续服务。它们的承诺时间、退款、漏领和退出风险不同，不能只按名义折扣排序。

## 6. 完整示例

某材料普通玩家每日可支配获得 100 个，目标礼包含 1,000 个，时间锚点为十天。若礼包还能节省一个每周限定次数，其价值不能只按材料数量计算；若玩家购买后会立即完成该系统，后续同类礼包价值将下降。

需要模拟未购买、购买一次和购买上限后的成长完成度及内容表现。若购买一次就跨过竞技关键阈值，应重新评估公平和匹配。

## 7. 商业化复盘

同时观察购买率、收入、重复购买、内容使用率、资源库存、成长差距、退款、投诉和购买后流失。高购买率可能来自强门槛或误导，不自动说明商品健康。

## 8. 定价工作表

每项商品记录实际支付、资源内容、免费获取时间、可支配日产量、适用玩家阶段、购买次数、购买后完成度、参照价和过期规则。混合礼包显示各项使用率，避免用大量无用物抬高标称价值。

## 9. 诊断例

某礼包购买率高但使用率低，可能是玩家为了其中一项关键材料被迫购买整包。应检查是否拆售、是否形成内容门槛，以及填充资源造成的库存。高购买率在这种情况下不是礼包健康的证据。

## 发布前检查

- [ ] 是否有免费或替代路径基线？
- [ ] 折扣参照是否真实可购买？
- [ ] 是否计算重复购买后的边际收益？
- [ ] 商品是否破坏内容和经济周期？
- [ ] 是否联合观察退款、投诉和流失？
