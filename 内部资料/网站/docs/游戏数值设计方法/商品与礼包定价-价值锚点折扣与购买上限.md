# 商品与礼包定价：价值锚点、折扣与购买上限

一次商品定价，先回答玩家为什么要买，再回答应该卖多少。常见错误是从折扣标签、竞品价格或内部战力换算开始，最后只能证明“看起来很值”，不能证明玩家真的获得了可理解、可替代、可控制的价值。

## 1. 先说明玩家得到什么

定价的对象不是一个价格点，而是玩家获得的结果。你需要先写清楚商品交付了什么资源、权限、时间节省、内容进入机会或服务承诺。若玩家买到的是资源，重点是它能推进哪个系统；若玩家买到的是外观或独占内容，重点是表达、稀缺定位和拥有感，而不是把它伪装成节省了多少时间。

这一步属于设计判断。设计者需要说明商品服务哪类玩家、解决哪个阶段的问题，以及购买后会怎样改变成长节奏。这个判断不能由“折扣很高”推出，也不能由“竞品也这样卖”推出。

没有免费路径的独占内容可以定价，但要承认它没有可直接折算的时间基线。此时可比较的是内容制作、审美表达、稀缺范围、持有期限和产品承诺，不是虚构一个玩家本来可以免费刷到的时间成本。

## 2. 建立免费或替代路径基线

有免费路径的商品，先计算目标玩家通过正常玩法取得同等内容所需的自然时间、有效游玩时间和机会成本。自然时间回答“日历上要等多久”，有效游玩时间回答“实际要玩多久”，机会成本回答“为了拿它放弃了什么”。三者经常不同，混在一起会高估或低估商品价值。

资源包可以从目标玩家的可支配日产量建立初始锚点，但要扣除基础必需消耗：

`可支配日产量 = 日总获取量 - 基础必需消耗量`

例如，玩家每日获得 50,000 金币，固定消耗 35,000 金币，可自由分配的基线是 15,000 金币。这个数只说明资源在当前经济里的替代路径，不说明玩家一定愿意为它付费。

这里记录的是内部等价换算。它适合比较同一系统内的资源量、成长速度和库存压力，不等于市场价格，也不等于玩家的真实边际价值。相同资源在系统刚开放、追赶阶段和毕业阶段的意义不同。

## 3. 估算混合礼包的真实可用价值

混合礼包不能把所有内容按标价相加。正确顺序是逐项估算替代路径，再判断组合是否产生协同或浪费。突破材料和刚好配套的金币放在同一礼包中，可能减少玩家额外补资源的成本；大量玩家已经毕业的填充物，即使内部标价很高，也不应足额计入玩家价值。

评估混合礼包时，先问每一项是否会被目标玩家使用，再问它是否改变其他内容的可用性。若一个礼包的购买率高但使用率低，可能不是礼包健康，而是玩家为了其中一项关键材料被迫购买整包。此时应检查是否可以拆售、是否形成内容门槛，以及填充资源是否正在制造库存。

统一战力、人民币换算或资源标价可以作为内部比较口径，但需要标注为内部换算。玩家看到的是实际支付、到账内容、使用限制、过期风险和购买后的系统进度。内部口径不能直接写成玩家可感知价值。

## 4. 校验折扣是否有真实参照

折扣是市场表达，不是价值计算。折扣必须对应真实可购买的参照价，并区分常驻单品价、历史成交价、礼包拆分价和活动价。永久显示的“限时折扣”，或从未按原价出售的虚高锚点，会损害价格信任。

比较商品时，不要只比较“百分之几折”。你需要同时比较实际支付、到账内容、使用限制、过期时间、漏领风险和退款条件。月卡、战令和订阅尤其容易出现名义价值很高、实际领取依赖很强的情况。

这一步记录的是市场事实。可购买参照、历史成交、活动周期和展示口径都应能被复核。若参照价不可验证，就不能把它用于折扣宣传。

## 5. 计算重复购买后的边际收益

商品第一次购买和第多次购买的价值常常不同。重复购买会改变玩家能力、库存和系统完成度，所以要按购买次数计算边际收益、模块完成度，以及与免费路径的差距。

一个材料礼包如果含 1,000 个材料，而普通玩家每日可支配获得 100 个，时间锚点是十天。若礼包还能节省一个每周限定次数，其价值不能只按材料数量计算；若玩家购买后会立即完成该系统，后续同类礼包的价值会下降。

购买上限用于保护经济、内容寿命和玩家预算，不只是制造稀缺。若前几次性价比很高、后续骤降，界面和规则要清楚展示，不让玩家依赖复杂换算才发现成本变化。

这里进入伦理护栏。若购买一次就跨过竞技关键阈值，定价评审不能只看收入和转化，应重新评估公平、匹配和非付费玩家的反制空间。

## 6. 选择商品结构并说明承诺

不同商品结构卖的不是同一种承诺。首购降低首次决策成本；月卡交换持续登录；战令交换周期参与；礼包提供明确资源组合；订阅承诺持续服务。它们的承诺时间、退款、漏领和退出风险不同，不能只按名义折扣排序。

选择结构时，要让玩家在购买前知道自己承担什么。一次性礼包的风险主要在内容是否可用；月卡和战令的风险在漏领、时间安排和中途退出；订阅的风险在续费、服务变化和取消路径。设计上可以引导长期参与，但不应把基础体验拆成不便，再出售便利。

## 7. 用三种状态验证成长影响

定价完成后，至少模拟未购买、购买一次和购买到上限后三种状态。每种状态都要看成长完成度、内容表现、资源库存和与免费路径的差距。这个检查能发现两个问题：商品是否只是在出售正常进度，商品是否让付费玩家过早越过内容寿命。

如果商品服务追赶，应确认它是否缩短落后玩家与主流内容之间的距离，而不是扩大竞技差距。如果商品服务深度玩家，应确认它是否消耗了未来内容节奏。高购买率可能来自真实需求，也可能来自强门槛或误导，不能自动说明商品健康。

## 8. 复盘时同时看收入和损伤

商业化复盘需要同时观察购买率、收入、重复购买、内容使用率、资源库存、成长差距、退款、投诉和购买后流失。只看收入会把短期压力误判为商品价值；只看购买率会把被迫购买误判为需求。

复盘结论要区分四类证据。实际成交、退款和投诉是市场事实；资源消耗、完成度和库存是内部系统证据；目标玩家阶段和商品定位是设计判断；公平、预算和误导风险是伦理护栏。四类证据同时成立，才说明商品可以继续扩大。

## 定价工作表

每项商品至少记录实际支付、资源内容、免费获取时间、可支配日产量、适用玩家阶段、购买次数、购买后完成度、参照价、过期规则和退款条件。混合礼包还要记录各项内容的使用率，避免用大量无用物抬高标称价值。

同一工作表中，应明确标注哪些数来自内部等价换算，哪些数来自市场事实，哪些结论是设计判断，哪些规则属于伦理护栏。标注清楚后，团队才能讨论分歧，而不是把不同性质的证据混成一个“价值很高”的结论。

## 发布前检查

- [ ] 是否有免费或替代路径基线？
- [ ] 折扣参照是否真实可购买？
- [ ] 是否计算重复购买后的边际收益？
- [ ] 商品是否破坏内容和经济周期？
- [ ] 是否联合观察退款、投诉和流失？
