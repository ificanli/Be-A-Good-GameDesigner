# 01 · 创意的六种入口

创意会若只问“有没有新玩法”，常得到题材替换、功能叠加和随机关联。更好的起点，是检查玩家动作与结果之间的关系：玩家做了什么，对象怎样变化，变化留下什么状态，下一次选择因此改变什么。

下面六种入口不是分类百科，也不是要求每个方案都套用的公式。它们的作用，是让团队从不同位置改动同一条行为链，然后尽快判断哪些候选有连续后果，哪些只是好听的名字。

## 1. 候选先落到动作

### 1.1 先把候选写成动词链

进入六种入口前，先要求候选用动词写完一次循环。“台球加构筑”仍然过宽；“瞄准发射—撞到的数字球进入五球槽—特殊墙加工撞墙球—决定结算或保留”才足够进入下一轮筛选。

《五球满贯》可以作为贯穿案例。它保留台球的瞄准、发射和碰撞，把“撞到球”从单纯得分改成收集数字、形成组合和触发特殊墙加工。规则改变后，玩家不应只追最近的球，而应在出杆前比较路线、容量、颜色和继续冒险的风险。

这条链给后续检查留下了观察点：玩家是否看得懂五球槽，是否会为了特殊墙改变角度，是否会在结算和继续之间犹豫。没有这些行为，候选仍然只是“台球换结算规则”。

## 2. 从成熟结构改出候选

### 2.1 入口一：替换成熟母体的高频结果

第一种入口是保留大部分熟悉规则，只替换一个高频结果。《五球满贯》替换的是台球中“撞球带来击打结果”的后续意义：被撞对象进入组合槽，特殊墙改变其价值，上一杆留下的球位又影响下一杆。

替换要成立，新结果必须反过来影响原操作。若玩家仍按传统台球只追求把球打进袋，构筑没有进入核心；若玩家因为组合和墙面效果改变出杆角度，替换才开始产生新判断。

《扫雷占城》提供一个边界案例。它保留数字提示与翻格，把安全格从解谜进度改为可行军、可争夺的道路或领土。现有原型暴露出它更像“扫雷生成道路的城池战争”，尚不能证明原定的轻量占城体验已经成立。这说明替换高频结果时，不能只让两个系统先后发生，必须让新结果改变下一次原操作。

### 2.2 入口二：把附属操作提升为主体

整理背包、刷新商店、安排队列、装箱和配菜，常在其他游戏里充当准备工作。把它们提升为主体时，该动作必须拥有可读状态、多个合理选择和连续后果。

如果把《五球满贯》的结算槽当作主体，关键就不是扩大界面或增加数字，而是让槽位、颜色、容量和保留决策持续影响下一杆。玩家保留某组球，下一杆就应面对更高收益和爆仓风险；玩家结算清空，则失去升级组合的机会但获得安全空间。

反例是只把背包、矿车或队列做成更大的容器。物品的位置、朝向、顺序或邻接如果不改变战斗、生产或路线，附属操作仍然只是整理，不会成为玩法主体。

### 2.3 入口三：删除惯常操作

删除瞄准、主动攻击、建造或移动，可以把注意力集中到剩余决策。删除不是单纯降低操作量。被删动作原本承担的信息和风险，需要转移到走位、构筑或时机选择上。

假如《五球满贯》删除精确瞄准，规则就必须把技巧转移到路线选择、球组保留或墙面时机上；否则玩家只是点击一个大致方向，等待系统替他完成精彩结果。删除后要问：玩家多观察了什么，又多承担了什么决定。

《贪吃蛇军火库》也能说明这条边界。若删除主动攻击，尾部朝向、身体加工和路线选择必须承担战斗风险；若玩家只需等待尾仓自动开火，删除攻击得到的是自动播放，不是新的玩法。

## 3. 从对象玩具和张力扩展候选

### 3.1 入口四：重写熟悉对象的价值

对象和输入保持熟悉，但规则持续改变“什么值得追求”。在《五球满贯》中，低数字球可能因当前颜色、组合、特殊墙和桌边徽章成为关键目标。价值变化必须在操作前可见，让玩家据此修改路线，而不是到结算时突然加分。

这类入口适合牌、骰子、装备、资源等已有稳定价值认知的对象。规则—行为—观察—结论链很直接：规则改变对象价值；玩家在选择前比较新价值；测试观察路线是否因此变化；若变化只发生在结算界面，说明价值改写没有进入高频操作。

### 3.2 入口五：先找到好玩的玩具

弹性碰撞、绳索、磁铁、液体和群体挤压等交互，可以先于关卡目标存在。判断标准不是“看起来新”，而是没有成长和奖励时，操作本身是否值得重复；相同输入在不同空间状态下，是否产生可学习的结果。

《五球满贯》的玩具层是弹射、反弹和连续撞击。若玩家在没有成长奖励时也愿意反复试角度，并能学会让目标球经过特殊墙，玩具就能支撑后续目标。若物理效果只值得看一次，继续增加任务也难以支撑长期玩法。

玩具原型应先验证可控性、反馈差异和状态变化，再寻找完整目标。否则，团队可能把“第一次看见很有趣”的演出误当成可重复学习的操作。

### 3.3 入口六：移植一种决策张力

可以移植“继续深入还是返回”“短期救急还是长期投资”“现在结算还是继续冒险”等关系，而不搬整套游戏。《五球满贯》把继续冒险放进有限杆数和五球容量里：保留球组再打一杆可能升级组合，也可能爆仓并浪费已经投入的杆数。

移植张力时，两端必须都真实存在。只有收益递增、没有可感知损失，不构成继续冒险；惩罚完全随机且无法管理，也只会造成挫败。测试时要观察玩家是否能解释风险来源，并主动在保留和结算之间改变策略。

## 4. 收敛误用并保留来源

### 4.1 用六个问题生成候选，再删除空洞表达

对一个熟悉母体依次提问：哪个高频结果可以被替换；哪个附属动作已经有选择但缺少反馈；删掉哪个惯常操作后，剩余判断会更集中；什么规则能改变对象的价值排序；哪个交互在没有奖励时仍然有趣；哪种张力可以进入每轮操作。

以三消为母体，可以得到六类胚子：让砖块成为持续存在的地形；把交换前的路线预览提升为主要规划；删除自由交换，只允许推动整行；让低价值颜色随局面变成关键资源；先验证整片网格坠落的物理玩具；移植“现在结算还是继续累积连锁”的张力。

这些只是胚子。下一步要补全主要输入、状态残留与压力。如果“推动整行”没有带来新的空间信息，它只是操作方式变化；如果“继续连锁”没有损失条件，它只是免费追加奖励。团队可以要求每位成员从不同入口各写一个动词链，再交叉组合；不要直接投票选最酷的名字，先删除无法形成连续后果的候选。

### 4.2 常见误用

第一种误用是把入口当成题材生成器。第二种是一次改变太多核心环节，导致玩家无法借用母体经验。第三种是先设计完整成长，再假设基础操作会因此好玩。

早期候选最好只声明一项核心变化，其余规则负责制造局面、压力与反馈，不争夺解释中心。六个入口负责拓宽搜索方向，机制检查负责淘汰空洞表达。
