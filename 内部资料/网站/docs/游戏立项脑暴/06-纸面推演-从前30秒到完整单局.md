# 06 · 纸面推演：从前 30 秒到完整单局

概念说明可以跳过大量细节，玩家却必须按顺序经历每一次输入、等待和结算。纸面推演的作用，是在写代码前把这些步骤展开，发现空窗、必选项、无法解释的状态和缺少高潮的循环。

## 先模拟连续十次输入

不要先写完整世界观和成长树。选择一个代表性局面，逐次记录：

| 次数 | 玩家看到什么 | 可选动作 | 选择理由 | 立即结果 | 留下的状态 |
|---:|---|---|---|---|---|
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |

十次输入能够暴露三个问题：玩家是否一直重复同一选择；精彩结果是否需要等待过久；系统是否在第四、第五次操作后才出现真正决策。

《贪吃蛇军火库》的纸面试玩按 30 秒分段：第一次吞入飞刀并看到分裂加工，随后在火焰与穿透之间选路线，再让尾部朝向敌人触发精准齐射。这个顺序把“加工链是什么”“选择有什么差异”“移动怎样影响射击”依次展示出来。

## 前 30 秒验证操作承诺

前 30 秒不需要解释全部系统，但应完成一次最小核心闭环：

```text
看见目标
→ 执行主要输入
→ 得到可理解反馈
→ 局面发生变化
```

若第一次成功依赖长教程、随机刷出特定对象或积累多轮资源，原型很难判断核心是否成立。可以为测试安排受控开局，但必须记录哪些内容是教学保护，不能误当成长期规则。

## 前三分钟验证决策升级

前三分钟至少应出现：

1. 第一次成功，让玩家知道操作有效；
2. 第一次二选一，让玩家理解不是照提示点击；
3. 第一次风险或失败，让玩家认识约束；
4. 第一次高潮，兑现方案最重要的画面；
5. 一个短期目标，说明为何继续。

《叠层矿场》旧原型的问题不是没有系统，而是第一屏同时出现叠层、矿车、三合、矿工、工作区、工具与配方。验收建议把教学拆成取牌三合、制作铁镐、取牌推进工作、铁镐挖岩石四段。纸面推演不只检查内容够不够，也检查玩家在每一分钟被要求理解多少关系。

## 推演完整单局

概念能支撑三分钟，不代表有完整游戏。单局推演应标出：

- 开局资源与安全空间；
- 压力何时、通过什么变量增加；
- 中段是否产生新的判断；
- 高潮由玩家怎样准备并触发；
- 胜负何时确定；
- 结算告诉玩家什么；
- 下一局为什么值得重开。

最好画出压力、选择密度和反馈强度三条时间曲线。持续高压会让玩家疲劳；长时间平坦说明循环缺少阶段；高潮若与前面的选择无关，只是预设演出。

## 同时推演三种玩家

标准流程容易把最优路线写成唯一体验。至少模拟：

- **初次玩家**：漏看提示、采取直觉操作；
- **谨慎玩家**：偏好稳定收益，回避风险；
- **激进玩家**：追求组合与高潮，容忍失败。

《坠楼消除》若谨慎玩家永远不拆低层，激进玩家永远等最大怪群再砸，说明不同策略可能成立；若所有玩家都在同一时机完成同一步，所谓风险收益可能只是算术答案。

## 记录空窗与行政操作

每一步都标记为观察、决策、执行、反馈、等待或整理。如果循环主体是等待生产、清理库存和点击确认，而招牌动作很少，系统即使自洽也可能乏味。纸面阶段应优先删除不产生判断的行政步骤，而不是靠加速按钮解决。

## 纸面推演记录表

```text
场景与初始状态：
当前短期目标：
玩家可见信息：

第 N 次输入：
- 可选动作：
- 选择理由：
- 立即反馈：
- 状态变化：
- 下一次新增或失去的选项：
- 等待与整理时间：

第一次成功发生在：
第一次真实选择发生在：
第一次风险发生在：
第一次高潮发生在：
胜负和重开理由：
```

推演完成后，将每次输入标成“有判断”“唯一答案”或“行政操作”。如果十次输入里只有一两次有判断，应先重新设计局面生成和后果传播。如果每一步都有多个选项但玩家无法读取其结果，则需要减少状态或补充预览。

## 用推演比较两个版本

比较方案时不要只写功能差异。将两个版本放在同一初始局面，模拟相同数量的输入，比较决策数量、反馈延迟、状态复杂度和高潮到达时间。例如《叠层矿场》从七格三合版本转向更完整的经营版本后，应检查经营需求是否真的改变取牌；如果只是增加拖拽和等待，旧版反而可能更集中。

## 纸面推演不能证明好玩

它只能排除明显断裂并形成原型假设。物理手感、操作负担、信息可读性与情绪释放仍需可玩版本验证。纸面上“精准尾射很有技巧”，只有玩家实际愿意绕弧线调整尾向时，才获得体验证据。

## 来源说明

本文依据五个候选的纸面试玩、前三分钟流程、教学拆分和原型验收记录整理。纸面推演与作者判断用于形成假设，不等同于玩家体验证据。
