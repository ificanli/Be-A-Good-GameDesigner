# 02 · 从成熟母体出发

以成熟玩法为母体，不是选择一个品类标签。真正可借用的是玩家已经掌握的操作语法、反馈预期和基本目标。只有把母体拆到动作层，团队才知道哪里可以改，哪里一改就会失去可理解性。

## 母体的最小结构

| 项目 | 需要描述的内容 |
|---|---|
| 主要输入 | 玩家反复点击、拖动、移动或发射什么 |
| 直接对象 | 输入作用于球、格子、牌、单位还是空间 |
| 即时结果 | 移动、翻开、碰撞、消除、占领或生产 |
| 局面残留 | 结果怎样改变下一次可选动作 |
| 成败压力 | 什么迫使玩家不能无限试错 |

以扫雷为例，输入是翻格或标记，对象是未知格，即时结果是数字、空区或地雷，局面残留是公开信息，压力来自误触。只说“扫雷是推理游戏”，无法指导后续融合。

## 找高频操作，不找主题符号

适合改造的环节通常频繁发生、结果可见，并影响后续选择。台球的瞄准与碰撞、贪吃蛇的转向与吞食、三消的交换与消除都符合。赌场、矿洞与战争只是包装，不能单独提供操作结构。

《贪吃蛇军火库》的设计与原型把吞下的对象分为组件和一次性武器，身体不只增加长度，还按顺序加工弹药。规则已经进入转向与吞食这组高频操作；但玩家是否会稳定理解组件顺序、主动据此规划路线，仍缺少充分外部观察。

## 区分必须保留与可以替换

可以用三个问题检查母体规则：

1. 删除这条规则后，玩家是否还会自然使用原操作？
2. 它是否提供了母体最主要的即时反馈？
3. 新规则能否承担它原来的压力和学习空间？

《扫雷占城》的方案保留数字与地雷，希望让开路具有推理和风险；传统扫雷“清空全部安全格”的目标则被占领敌城替代。现有原型初步说明翻格能够影响战争路线，但实际主体更偏城池攻防，尚未证明扫雷与占城达到了预期的融合深度。

## 用状态残留检验改造深度

一次操作如果只提供资源，再被新系统消耗，联系通常较浅。更强的改造会让结果留在原场地。《五球满贯》中已收数字球仍留在台面，成为反弹跳板或障碍；特殊墙还会同时修改实体球和组合槽。上一杆的收集因此改变下一杆球路，而不是“撞球结束后去菜单配牌”。

状态残留可以是位置、顺序、道路、公开信息、容量或风险。它负责把新规则传播到下一次输入。

## 建立母体动作卡

```text
母体：三消
输入：交换相邻格
即时反馈：匹配、清除、下落与连锁
可见状态：颜色布局与特殊棋子
压力：步数、时间或目标
可替换环节：消除结果、补充规则、棋盘损失、目标对象
主要生产风险：关卡内容消耗与死局
```

《坠楼消除》替换了消除结果：横消削弱支撑，纵消制造坠石；支撑断裂后，上方楼体坠落。建筑高度同时是棋盘、武器和防线。这个设计主张清晰，但仍需试玩验证楼道与棋盘能否同时可读，玩家是否真的愿意等待怪物聚集再砸楼。

## 案例对照：保留输入，替换结果

五个参考原型都尽量保留了母体中最易理解的输入：台球仍然瞄准发射，扫雷仍然翻格看数字，贪吃蛇仍然转向吞食，三消仍然交换相邻砖块，叠层取牌仍然点击未被覆盖的牌。变化集中在结果与后果：撞球形成组合，安全格成为道路，身体加工弹药，消除破坏建筑，取牌进入经营循环。

这种做法的优点是玩家可以先凭旧经验完成第一次输入，再从异常结果中学习新规则。风险在于旧策略可能仍然完全有效。如果《扫雷占城》的最佳方式只是先把地图安全扫完再出兵，占城并没有改变翻格；如果玩家在《贪吃蛇军火库》中只追逐所有掉落物，组件顺序没有影响路线，新机制也未进入判断。

因此，母体改造完成后还要比较“旧策略”和“新策略”。新规则应使部分旧习惯失效或产生机会成本，但不必让所有旧知识作废。

## 不要向母体的历史习惯缴税

成熟不代表每条旧规则都适合当前项目。真实台球的复杂旋转、三消的大量手工关卡、传统贪吃蛇的一碰即死，都可能违背短周期原型目标。借用母体是为了降低理解成本和获得已知反馈，不是完整复制。每一条保留规则都应说明它服务于哪项体验。
