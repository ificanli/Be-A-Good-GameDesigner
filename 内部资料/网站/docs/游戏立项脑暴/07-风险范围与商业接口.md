# 07 · 风险、范围与商业接口

本篇只完成一个阅读任务：在候选方案进入原型前，决定先验证什么、暂时不做什么，以及哪些商业想法只能作为接口保留。

这一步发生在写原型任务之前。团队若先讨论完整成长、商店、八轮内容和宣传素材，就会把三类问题混在一起：玩法可能不成立，制作可能失控，产品化接口可能没有空间。它们都重要，但它们不在同一个时间点回答。

《五球满贯》适合贯穿这一轮判断。它的卖点不是“有很多桌、很多徽章”，而是玩家通过真实弹射、一杆多撞、特殊墙加工和组合得分，产生可学习的球路规划。如果这个链条无法被理解或稳定实现，后面的庄家、长局和商业扩展都没有可靠地基。

## 先把失败原因分层

风险排序不是列出所有担忧，而是找出最早会推翻项目理由的那一项。《五球满贯》的第一层体验风险是：玩家是否能读懂拖拽发射后的碰撞因果，是否会为了让数字球进入组合而规划球路，以及一杆多撞是否带来明确正反馈。若玩家只是在随机碰球，核心主张就没有成立。

第二层是技术与表现风险。实际物理、辅助线和结算逻辑必须使用一致的碰撞规则，否则试玩者失败时，团队无法判断问题来自空间判断还是实现误差。固定时间步长、碰撞预测、停止节奏、复制墙和染色墙的规则复查，都不是后期优化；它们决定证据是否干净。

第三层是内容与运营风险。多桌目标、十二枚徽章、两小时目标曲线、爆仓率和过桌率，会影响产品是否能扩展到长局，但它们不能先替代核心验证。一个早期原型可以记录这些未知项，却不应因为它们显得“完整”而提前制作。

其他项目能作为反例提醒边界。《坠楼消除》的致命风险不是 Boss 数量，而是三消、支撑、坠落清怪和棋盘缩短能否形成可读取舍；《叠层矿场》的第二关若要求固定、高难但可解，状态搜索比永久成长更早；《扫雷占城》若翻格不能直接改变战争路线，加兵种只会把融合问题藏起来。

## 用最低成本验证最高风险

风险越致命，验证越要早，也越要便宜。便宜不等于粗糙；它表示只做足以回答当前问题的证据。

| 风险 | 低成本验证 |
|---|---|
| 规则难懂 | 连续输入纸面演示、无解释复述 |
| 选择单一 | 状态枚举、纸面多策略推演 |
| 物理不可控 | 只做发射、碰撞和预测的玩具 |
| 关卡可能无解 | 状态搜索或规则求解器 |
| 信息过载 | 灰盒界面与首玩观察 |
| 长线组合不足 | 组件交叉关系矩阵 |

在《五球满贯》中，先做“发射—碰撞—墙加工—组合得分”的玩具，比先做完整赛季更能回答问题。规则行为链应写清楚：玩家拖拽发射，数字球沿辅助线进入碰撞；球撞到特殊墙后改变状态；激活球进入组合槽；组合和徽章触发结算；玩家根据这次结果调整下一杆。观察若显示玩家能主动解释和复用这条链，结论才是“核心可继续验证”。若辅助线漂移或停止节奏不稳，结论只能是“实现污染测试”。

## 用 MUST、SHOULD、CUT 冻结原型范围

范围冻结的目的不是压低功能数量，而是说明每一项实现服务哪条决策证据。写范围时，先把功能放进三类：

```text
MUST：缺少后无法验证核心主张；
SHOULD：核心获得当前证据后，用于提高完整度；
CUT：当前阶段明确不做，防止讨论重新膨胀。
```

《五球满贯》的第一版 MUST 应保留拖拽发射、真实碰撞、辅助线、基础球桌、复制墙或染色墙、组合槽、目标分和最小胜负。SHOULD 可以是少量徽章、两三张桌面目标和更强结算表现。CUT 则包括完整八轮内容、十二枚徽章、商店、收藏、赛季目标和复杂庄家成长。

《贪吃蛇军火库》的切法提供了同样的反例：原型保留移动、武器加工、尾仓和精准尾射，删除经验三选一、整理果和完整 Boss。它不是否认外围系统价值，而是把测试集中到加工链是否可读、组件顺序是否形成选择、尾部射击是否改变移动。

范围冻结还应写三至五条核心不变量。《五球满贯》可以冻结：数字球必须通过真实碰撞进入组合；特殊墙只加工实际撞墙的激活球；辅助线与实际碰撞必须一致；组合得分必须来自玩家这一杆的准备，而不是自动播放。实现中若这些不变量无法成立，应暂停并报告，不要悄悄改成另一种合成游戏。

## 商业接口只检查兼容性

商业评估可以提前做，但它在这里回答的是“核心是否给未来产品化留接口”，不是“付费表怎样设计”。在核心证据成立前，抽卡、挂机收益、战力墙和礼包不能替玩法补血。

健康的接口通常来自选择扩展：更多构筑路线、可收藏的桌边徽章、外观、赛季目标、自然停顿点的奖励广告。《五球满贯》若能证明功能墙、数字球和徽章之间产生不同规划，就有内容乘法的可能；新增一枚只提高倍率的徽章，则更接近线性内容。可以用关系矩阵检查新内容是否改变旧选择：它是否改变操作顺序、空间路线、风险承担或结算准备。只有数值变大，不应算作新玩法。

商业红线也要在此时写下：广告展示的玩法不能不同于实际核心；不能故意制造痛苦再售卖跳过；付费不能只有线性战力；不付费不能缺失机制完整形态；连续决策中不应频繁打断。若真实素材必须伪造球路、跳过等待或隐藏无聊过程才能成立，素材反而暴露了核心问题。

## 形成一页风险与范围表

这一页是下一篇最小原型的输入。它不替代策划案，只回答“为什么现在做这些，不做那些”。

```text
核心体验假设：
最致命体验风险：
最致命技术风险：
最致命内容风险：
各自最低成本验证：
MUST：
SHOULD：
CUT：
核心不变量：
长线内容接口：
商业红线：
停止条件：
```

写完后再检查证据链是否完整：规则是什么，玩家会做什么，团队准备观察什么，观察结果支持或反驳哪条结论。比如《五球满贯》的链条不是“弹射很爽”，而是“真实碰撞和墙加工让玩家能准备一杆多撞；若玩家主动规划球路并复述组合后果，则支持继续做完整局；若玩家理解后仍不规划，或实现无法稳定预测，就返回机制或停止”。
