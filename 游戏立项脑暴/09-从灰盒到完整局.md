# 09 · 从灰盒到完整局

本篇只完成一个阅读任务：当最小原型支持核心假设后，把灰盒扩成一局能开始、变化、高潮、结算并重开的体验切片。

灰盒能证明单次交互成立，却常常还只是玩具。玩家可以反复发射、碰撞或合成，但不知道为什么开始、何时紧张、怎样赢输，以及下一局为什么值得再试。完整局不是立刻堆系统，而是让核心机制承担一条可理解的体验曲线。

《五球满贯》在这一步的主问题是：弹射和一杆多撞已经有初步正反馈后，能否形成一局从第一杆到胜负的节奏，而不是只留下一个可以无限试手感的台球玩具。

## 先确认灰盒闭环没有断

扩展前先检查最小闭环：

```text
观察局面
→ 做出主要输入
→ 得到即时反馈
→ 看见局面后果
→ 准备下一次选择
```

《五球满贯》若还存在拖拽不稳、辅助线不准、球停不下来、墙加工看不清或组合结算不可预测，就不该进入完整局。标题页、收藏和商店不能提高核心证据强度。它们只会让团队误以为“更像产品”就是“更能判断”。

## 给一局安排五个阶段

完整局需要五个阶段，但它们不一定是五个界面。关键是玩家能感到自己从入门、选择、承压、兑现到复盘，经历了一段由核心规则推动的曲线。

第一阶段是进入与第一次成功。《五球满贯》应让玩家在十秒左右知道能拖拽发射，并在低风险桌面上撞出一次清楚结果。第一杆不必要求复杂规划，但必须让玩家看见“我打出去的球导致了状态变化”。《叠层矿场》的反例是第一屏同时展示多个区域，玩家还没取第一张矿牌就要理解完整生产系统，首玩失败很难归因。

第二阶段是第一次真实选择。教程不能一直给唯一答案。《五球满贯》应尽快出现两个理由不同的球路：一条更安全但收益低，一条需要撞特殊墙并承担散球风险。若玩家只是选分数更大的一边，选择还不够真实。《贪吃蛇军火库》中火焰路线更危险但适合群体、穿透路线更安全并改变后续武器表现，也是在建立同类判断。

第三阶段是压力升级。压力应迫使玩家改变方法，而不是单纯提高目标分。可用空间减少、组合槽接近爆仓、剩余杆数不足、目标球位置变差、功能墙需要提前准备，都能推动策略变化。《扫雷占城》的反例是，如果敌方没有同步开路并争夺中立城，“安全慢扫”就可能永远成立，战争路线不会反过来影响扫雷选择。

第四阶段是高潮兑现。高潮需要前面的选择参与准备。《五球满贯》的理想高潮不是自动播放大数字，而是玩家把指定球撞向染色墙，形成组合，随后徽章依次触发并越过目标分。表现放大因果，不能替代因果。

第五阶段是结算与重开。结算应回答玩家为什么赢或输、哪一杆产生关键结果、下一局可以改变什么。只显示“胜利”无法帮助复盘。快速重开也是核心测试工具，因为它暴露玩家是否愿意马上验证新球路。

## 使用三分钟体验门检查结构

三分钟不是所有产品的最终时长，而是一个可评估切片。长线产品也需要先证明短切片能站住。

```text
十秒内知道第一步；
三十秒内完成一次核心闭环；
一分钟内出现招牌机制；
中段出现压力变化或新选择；
至少有一次由玩家准备的高潮；
有明确胜负和即时重开；
失败后能说出下一次准备改变什么。
```

《五球满贯》早期版本已经能拖拽发射、连续撞球、使用复制墙和染色墙，也有简单胜负。作者试玩中，多球碰撞比其他候选带来更明确的即时正面感受，因此值得进入完整化；这只支持“继续验证”。阶段验收仍指出标题、首次教学、关卡递进、关后成长和结算高潮不足，说明它还没有完成完整参赛体验。

## 画出压力曲线，再加内容

把一局按时间切成若干段，为每段写新信息、主要选择、失败压力和预期高潮。这样做能防止内容添加变成均匀铺开。

```text
阶段：
新信息：
主要选择：
失败压力：
预期高潮：
玩家应学到什么：
下一段为什么不同：
```

《五球满贯》后续加入多桌目标、桌边徽章和庄家规则后，产品完整度提高，也产生新的验证任务：一轮耗时、平均单手分、爆仓率、过桌率和徽章触发是否支持长局。若一局后半段只是前半段目标分更高，应先寻找新的判断；若新规则每分钟增加一种，玩家又会失去掌控。完整局需要在熟悉和变化之间保持可追踪的因果。

## 完整不等于系统多

《五球满贯》早期原型已有球桌、组合槽、庄家生命和胜负，在作者验收中仍被判断为缺少完整参赛体验，原因包括教学不足、结算高潮较弱和长期结构不清。增加八轮内容后，两小时目标曲线、功能墙使用率和徽章流派仍未得到充分外部验证。功能数量与体验完整度是两件事。

扩展顺序应保持克制：

```text
输入与核心因果稳定
→ 第一次成功与最小教学
→ 第一次真实选择
→ 压力升级
→ 高潮与胜负
→ 重开和复盘
→ 少量内容变化
→ 长线结构
```

如果核心在灰盒阶段没有产生期待、掌控或局面变化，应回到机制，而不是继续完成后续清单。
