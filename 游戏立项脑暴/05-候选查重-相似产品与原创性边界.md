# 05 · 候选查重：相似产品与原创性边界

查重不是证明“世界上从未有人做过”。检索不到也只能说明暂未发现，不能证明原创。它真正服务的决策是：候选是否值得继续投入，差异应做进哪个原型环节，哪些部分只是题材或外围功能不同。

《怪物海关》是贯穿案例。它曾保留概念吸引力，但搜索后发现它与《Lil' Guardsman》在奇幻关卡、有限调查工具、放行或拒绝及决定影响未来等结构上高度接近，因此被淘汰。这个案例说明，查重看的不是名称相似，而是玩家每轮做什么判断。

## 1. 确定查重时机和检索方式

### 1.1 先等候选足够具体，再做第一次查重

查重应发生两次。第一次在候选进入详细方案前，用较低成本排除高度撞车；第二次在核心规则明确后，针对高频操作和胜负结构做深度比较。

过早查重会让结果过宽。只有题材和一句模糊概念时，“怪物海关”可能搜到大量奇幻、怪物和审查题材，却无法判断核心是否相同。至少先写出主要输入、状态载体、操作结果、胜负目标和连续后果。

也不要等原型完成后才搜索。那时团队已经投入制作，容易为了沉没成本强调微小差异，把“角色更多”“剧情不同”“商业化更适合”误当成核心区别。

### 1.2 用行为词组合检索，不只搜题材

查重词要贴近玩家经历，而不是只贴近包装。每个候选至少组合以下词组：

```text
母体 + 题材
母体 + 核心机制
主要对象 + 高频操作
胜利目标 + 关键约束
状态载体 + 选择结果
```

“怪物海关”只能找到题材相似。“奇幻关卡、有限调查工具、放行或拒绝、决定影响未来”更接近玩家实际经历，也更容易找到《Lil' Guardsman》这样的结构近邻。

中英文、Steam 标签、移动商店、视频和开发者介绍应交叉使用。不要引用短视频广告就推断完整玩法，也不要把玩家评论当成官方规则；关键结论应尽量由实机视频、商店说明和实际试玩交叉确认。

## 2. 比较结构并记录差异

### 2.1 比较四个核心结构

相似产品出现后，不要先比较美术、角色和剧情。先比较四个结构：高频操作、状态载体、胜负目标和连续后果。

《怪物海关》的风险在于，高频操作同样是使用有限调查工具判断对象，状态载体同样是当前关卡中的可疑角色和线索，核心决定同样是放行或拒绝，后果同样会影响未来。若这些判断成立，换成不同怪物设定也不足以支撑“新核心玩法”。

差异必须写成玩家行为。“策略更深”“角色更多”“更适合商业化”都不是机制差异。真正可用的差异应说明玩家多观察了什么，多比较了什么，当前决定怎样改变后续局面。

### 2.2 写差异卡，而不是保存链接列表

查重结果应进入同一张差异卡。

```text
候选名称：
最接近的三款产品：
相同的高频操作：
相同的状态与目标：
本方案新增的玩家判断：
新增判断留下的连续后果：
只有题材不同的部分：
结论：保留 / 高风险 / 淘汰
仍需验证：
```

对《怪物海关》来说，差异卡的结论是淘汰完整方案，而不是抹掉所有想法。若相同部分已经覆盖高频操作、状态与未来后果，团队不应继续用题材差异辩护。

## 3. 从相似结论回收决策

### 3.1 淘汰后保留可复用关系

淘汰不代表讨论毫无产出。《怪物拍卖行》也进入已有恶魔竞拍和怪物阵容构筑的交叉区，但其中“购买行为改变后续价格、竞争者欲望与供给”的抽象关系仍可回收。

正确做法是保留可复用机制，不保留换皮后的完整方案。规则—行为—观察—结论链可以这样写：规则让购买改变后续市场；玩家因此不只评估当前怪物，还预测价格和对手需求；查重发现已有产品已覆盖怪物竞拍加阵容构筑；结论是更换状态载体重新验证，而不是继续推进原方案。

### 3.2 相似不等于必须放弃

成熟母体天然会与大量作品相似。保留候选的条件，是能够指出操作层的新判断，并提出可验证的连续后果。

《五球满贯》与台球游戏共享瞄准和碰撞，与组合构筑共享收集和结算。它的差异主张在于玩家通过真实球路选择组合素材，并把指定球撞向特殊墙加工。这个主张还需要和相近弹射构筑产品继续比较，但不能只因“都有台球”就判定撞车。

若市场已有多个弹射构筑产品，原型必须尽早检验“把指定数字球撞向特殊墙加工组合”是否足够高频、可控和可见。若这个行为很少发生，差异只存在于策划案中，项目会重新落入相似区域。

### 3.3 查重结果怎样变成设计决策

发现相似产品后，按相似程度处理。题材相似但操作不同，可以保留并调整传播表述。母体和操作相似，但连续后果不同，需要把差异做进首个原型。高频操作、状态载体和目标都相似，默认淘汰。只有外围成长不同，不作为保留理由。

查重也会改变测试重点。若候选依赖某个差异判断存活，下一版原型就要优先证明这个判断真的高频出现。不能把最能证明原创性的部分推迟到后期内容里。

## 4. 留下证据边界

### 4.1 记录日期和证据边界

产品持续更新，早期判断可能过时。资料卡应保存检索日期、版本、链接和当时观察到的核心循环。正式立项、对外宣传与发布前分别复查。

查重无法替代法律意见，也不能保证商业安全。公开发布时还需注意名称、素材、代码、专利和商标等问题。本系列讨论的是设计筛选：帮助团队判断候选是否值得投入原型，而不是给出知识产权结论。

### 4.2 来源说明

本文依据作者脑暴与商业分支中的候选查重流程、淘汰记录整理。查重结论只反映记录日期内发现的公开资料，不证明绝对原创，也不替代法律意见。
