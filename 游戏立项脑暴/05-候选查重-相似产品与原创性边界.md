# 05 · 候选查重：相似产品与原创性边界

查重的目的不是证明“世界上从未有人做过”，而是确认候选是否仍能为玩家提供不同的高频判断，并提前发现团队正在重复已有产品的核心。检索不到也只能说明暂未发现，不能证明原创。

## 什么时候查重

查重应发生两次。第一次在候选进入详细方案前，用较低成本排除高度撞车；第二次在核心规则明确后，针对高频操作和胜负结构做深度比较。若等原型完成后才搜索，团队容易因沉没成本为微小差异辩护。

过早查重也有问题。只有题材和一句模糊概念时，搜索结果会非常宽泛。至少先写出主要输入、状态载体、操作结果、胜负目标和连续后果。

## 组合检索而不是只搜题材

每个候选至少组合以下词组：

```text
母体 + 题材
母体 + 核心机制
主要对象 + 高频操作
胜利目标 + 关键约束
状态载体 + 选择结果
```

“怪物拍卖”只能找到题材相似；“竞拍怪物组成自动战斗阵容、购买影响后续价格”更接近玩家实际经历。中英文、Steam 标签、移动商店、视频和开发者介绍应交叉使用。

## 比较四个核心结构

| 结构 | 需要比较的内容 |
|---|---|
| 高频操作 | 玩家每轮实际点击、拖动或移动什么 |
| 状态载体 | 手牌、网格、队列、物理空间还是市场价格 |
| 胜负目标 | 怎样赢、怎样输、何时结算 |
| 连续后果 | 当前选择怎样改变后续局面 |

如果四项中的前三项高度相同，仅增加角色、构筑深度、美术与商业化，通常不足以支撑“新核心玩法”的定位。

## 用差异卡记录结论

```text
候选名称：
最接近的三款产品：
相同的高频操作：
相同的状态与目标：
本方案新增的玩家判断：
新增判断留下的连续后果：
只有题材不同的部分：
结论：保留 / 高风险 / 淘汰
仍需验证：
```

差异必须用玩家行为描述。“策略更深”“角色更多”“更适合商业化”都不是机制差异。

## 淘汰案例怎样提供价值

`NewGame` 曾保留《怪物海关》的概念吸引力，但搜索后发现它与《Lil' Guardsman》在奇幻关卡、有限调查工具、放行或拒绝及决定影响未来等结构上高度接近，因此淘汰。《怪物拍卖行》也进入已有恶魔竞拍和怪物阵容构筑的交叉区。

淘汰不代表讨论毫无产出。《怪物拍卖行》中“购买行为改变后续价格、竞争者欲望与供给”的抽象关系仍可回收，放进其他状态载体重新验证。应该保留可复用机制，不保留换皮后的完整方案。

## 相似不等于必须放弃

成熟母体天然会与大量作品相似。保留候选的条件是能够指出操作层的新判断，并提出可验证的连续后果。《五球满贯》与台球游戏共享瞄准和碰撞，与组合构筑共享收集和结算；它的差异主张在于玩家通过真实球路选择组合素材，并把指定球撞向特殊墙加工。这个主张还需要和相近弹射构筑产品继续比较，但不能只因“都有台球”就判定撞车。

## 查重结果怎样进入设计决策

查重不应只生成链接列表。若发现相似产品，应分别处理：题材相似但操作不同，可以保留并调整传播表述；母体和操作相似，但连续后果不同，需要把差异做进首个原型；高频操作、状态载体和目标都相似，默认淘汰；只有外围成长不同，不作为保留理由。

查重也能帮助选择测试重点。若市场已有多个弹射构筑产品，原型必须尽早检验“把指定数字球撞向特殊墙加工组合”是否足够高频、可控和可见。若这个行为很少发生，差异只存在于策划案中，项目会重新落入相似区域。

## 查重记录的维护

产品持续更新，早期判断可能过时。资料卡应保存检索日期、版本、链接和当时观察到的核心循环。正式立项、对外宣传与发布前分别复查。不要引用短视频广告就推断完整玩法，也不要把玩家评论当成官方规则；关键结论应尽量由实机视频、商店说明和实际试玩交叉确认。

## 查重的边界

查重无法替代法律意见，也不能保证商业安全。公开发布时还需注意名称、素材、代码、专利和商标等问题。本系列讨论的是设计筛选：帮助团队判断候选是否值得投入原型，而不是给出知识产权结论。

## 来源说明

本文依据作者脑暴与商业分支中的候选查重流程、淘汰记录整理。查重结论只反映记录日期内发现的公开资料，不证明绝对原创，也不替代法律意见。
