# 03 · 机制创新的判断

新增角色、技能、成长与题材可以丰富产品，却不一定改变玩家怎样玩。立项阶段要问的不是“这个规则新不新”，而是它是否进入玩家反复执行的动作，并持续产生以前不存在的观察、取舍或技巧。

《贪吃蛇军火库》适合做主要案例。它的候选规则是“蛇身加工弹药”：玩家吞下组件和武器，身体顺序影响加工结果，尾仓与尾部朝向影响释放。这个规则看起来是机制创新，但必须经过行为检查，而不是靠概念名判断。

## 1. 写出机制因果和操作位置

### 1.1 先把机制写成因果链

机制至少要写成四段：

```text
玩家输入
→ 对象发生变化
→ 留下新的局面
→ 新局面改变下一次选择
```

《贪吃蛇军火库》的链条可以写得更具体：玩家转向吞食组件；组件进入身体顺序；后续武器沿身体加工并进入尾仓；玩家下一次移动要同时考虑拾取路线、加工顺序、尾部保护和射击角度。

这条链若成立，新增规则就不只是武器系统。它会改变贪吃蛇的路线判断。若玩家只要吃到任何掉落物就变强，下一次选择没有变化，机制就退回到普通道具加成。

《叠层矿场》提供一个边界。旧原型实现过“点击未遮挡矿牌—牌进入七格矿车—三张同类生成实体材料—材料交给矿工制作工具—工具移除岩石并暴露底牌”的因果链。规则能运行，但后续试玩表明“系统互相连接”不等于“过程已经好玩”；如果生产只增加分数，不改变叠层，两个系统的联系还会进一步减弱。

### 1.2 检查一：它是否影响高频操作

新规则要说明影响哪个每 3～20 秒发生的动作。“有 Roguelike 构筑”不是答案；“玩家为了让尾部朝向敌群而绕弧线移动”才是答案。

在《贪吃蛇军火库》中，高频操作仍是转向和吞食。身体加工要成立，就必须让玩家在这些动作中额外观察组件、武器、身体顺序和尾向。只在关后选择一个弹药升级，或只在结算数字里体现加工结果，都很难成为核心创新。

## 2. 验证新判断、状态和学习

### 2.1 检查二：它是否产生新的判断

加入规则前后，玩家观察的信息和比较的选项必须变化。没有新观察，就不会有新判断。

身体加工的新增判断至少包括：先吃组件还是先吃武器；为了某个组件顺序是否绕远；尾仓是否留给更强加工结果；尾部是否转向敌人或保留安全空间。测试时要观察玩家能否说出这些差异，并在局面中改变路线。

《扫雷占城》的设计目标也是新增判断：数字不只帮助避雷，还影响开路速度、兵力成本和接近中立城的路线。原型是否真的让玩家据此改变翻格方向，仍需观察；若玩家仍只按传统扫雷的安全答案点击，新系统就没有产生新的判断。

### 2.2 检查三：它是否留下状态

操作后的状态残留，决定机制能否传播到下一轮。残留可以是位置、顺序、道路、容量、风险或公开信息。若特效结束后状态恢复原样，创新只能提供短暂新鲜感。

《贪吃蛇军火库》的残留是身体长度、组件顺序和尾仓弹药。玩家这次吞什么，会影响之后的加工和射击；身体变长还会同时提高火力与移动压力。这样的残留能把一次选择传到后续路线。

《坠楼消除》展示另一种残留：拆低层会造成更大坠落，也永久缩短棋盘和防线。当前清场与后续风险由同一次操作连接。若测试中玩家永远等怪最多时才砸，说明代价没有形成足够差异，需要调整规则，而不是只加强坠落特效。

### 2.3 检查四：它是否形成可学习能力

机制创新应让玩家通过练习掌握一项可复用能力。它可以是判断反弹角度、安排组件顺序、控制资源槽位或选择开图方向。如果表现差异主要来自永久数值，玩家学到的是“先升级”，而不是怎样玩得更好。

对《贪吃蛇军火库》来说，可学习能力应包括路线规划、顺序安排和尾向调整。原型还要验证加工过程是否可读，顺序差异是否足够明显，尾部参与是否增加技巧而不是操作负担。若玩家看不懂组件怎样加工弹药，机制再复杂也不会转化成学习空间。

## 3. 判断核心程度和传播后果

### 3.1 用删除测试判断核心程度

把候选中的创新规则删掉，再观察玩家动词、目标与最优策略。若几乎不变，大概率是附加功能；若主循环仍能运行，但关键取舍明显变化，可能是有效微创新；若主要乐趣与辨识度同时消失，规则已经进入核心。

以《贪吃蛇军火库》为例，若删除身体加工，玩家只剩下吃武器再从尾部射击，组件顺序、路线选择和加工表现都会失去意义。这个删除结果说明加工链具有核心地位。至于玩家能否在战斗压力下理解顺序，仍需试玩验证。

相反，“吃到红色道具后攻击力提高 20%”删除后，操作、观察和局面几乎不变。即使加入大量 Buff，也更接近内容扩充，而不是机制创新。

### 3.2 用传播测试检查连续后果

有效机制不会只改变点击瞬间，还会形成连续后果：

```text
这次选择改变位置或资源
→ 改变下一次可选动作
→ 迫使玩家调整路线或构筑
→ 最终形成可见高潮
```

身体加工的传播链应从吞食开始，经过身体顺序和尾仓，最后变成一次玩家准备过的精准尾射。若高潮与前面选择无关，只是系统定时播放强力攻击，传播链就断了。

## 4. 记录评分与创新边界

### 4.1 机制候选评分卡

每项只写证据，不急于打总分。

```text
影响的高频动作：
新增观察信息：
新增的两个合理选择：
当前选择留下的状态：
玩家可以学习的能力：
删除后损失什么：
十秒高潮怎样由玩家准备：
最可能证伪它的测试：
```

填不出“新增观察信息”和“当前选择留下的状态”的候选，不宜进入完整方案阶段。机制筛选的结论应写成“值得验证哪些主张”，而不是“这个方案已经创新且好玩”。

### 4.2 创新强度不是越高越好

陌生规则会增加教学成本和实现风险。短周期项目通常更适合保留熟悉输入，只改变一个持续可见的结果或约束。创新评价应与可理解性、反馈质量和学习空间一起判断，不能用“以前没见过”覆盖操作笨拙的问题。

以下内容通常不能单独承担机制创新：新题材、新角色、额外技能、局外成长、随机 Buff、结算倍率与商业系统。它们只有在改变高频操作的信息、约束或结果时，才会进入机制层。

### 4.3 来源说明

本文依据作者脑暴记录中的机制检查、删除测试与传播测试，并结合五个原型的设计、实现和有限试玩状态整理。案例结论只使用其当前证据层级。
