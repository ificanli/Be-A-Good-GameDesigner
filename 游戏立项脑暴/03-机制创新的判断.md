# 03 · 机制创新的判断

新增角色、技能、成长与题材可以丰富产品，却不一定改变玩家怎样玩。立项阶段需要判断新规则是否进入高频行为，并持续产生以前不存在的观察、取舍或技巧。

## 把机制写成因果链

```text
玩家输入
→ 对象发生变化
→ 留下新的局面
→ 新局面改变下一次选择
```

《叠层矿场》旧原型实现过这样一条因果链：点击未遮挡矿牌，牌进入七格矿车，三张同类生成实体材料，材料交给矿工制作工具，工具移除岩石并暴露底牌。这条链在规则上可运行，但后续试玩表明“系统互相连接”不等于“过程已经好玩”；如果生产只增加分数，不改变叠层，两个系统的联系还会进一步减弱。

## 四项检查

### 操作检查

新规则影响哪个每 3～20 秒发生的动作？“有 Roguelike 构筑”不是答案；“玩家为让蓝 5 撞上红色染色墙而改变出杆角度”才是。只在关后选择或结算数字中出现的规则，很难成为核心创新。

### 判断检查

加入规则前后，玩家观察的信息和比较的选项是否变化？《扫雷占城》的设计目标是让数字不只帮助避雷，还影响开路速度、兵力成本和接近中立城的路线。原型是否真的让玩家据此改变翻格方向，仍需观察；若玩家仍只按传统扫雷的安全答案点击，新系统就没有产生新的判断。

### 局面检查

操作是否留下位置、顺序、道路、容量、风险或公开信息上的后果？局面残留让一次选择传播到下一轮。若特效结束后状态恢复原样，创新只能提供短暂新鲜感。

### 学习检查

玩家能否通过练习掌握一项可复用能力？它可以是判断反弹角度、安排组件顺序、控制资源槽位或选择开图方向。如果表现差异主要来自永久数值，玩家学到的是“先升级”，而不是怎样玩得更好。

## 删除测试

把候选中的创新规则删掉，再观察玩家动词、目标与最优策略：

- 几乎不变：大概率是附加功能；
- 主循环仍能运行，但关键取舍明显变化：可能是有效微创新；
- 主要乐趣与辨识度同时消失：规则已经进入核心。

以《贪吃蛇军火库》为例，若删除身体加工，玩家只剩下吃武器再从尾部射击，组件顺序、路线选择和加工表现都会失去意义。这个删除结果说明加工链具有核心地位。至于玩家能否在战斗压力下理解顺序，仍需试玩验证。

## 传播测试

有效机制不会只改变点击瞬间，还会形成连续后果：

```text
这次选择改变位置或资源
→ 改变下一次可选动作
→ 迫使玩家调整路线或构筑
→ 最终形成可见高潮
```

《坠楼消除》中，拆低层会造成更大坠落，也永久缩短棋盘和防线。当前清场与后续风险由同一次操作连接。若测试中玩家永远等怪最多时才砸，说明代价没有形成足够差异，需要调整规则，而不是仅加强坠落特效。

## 区分机制创新与功能创新

以下内容通常不能单独承担机制创新：新题材、新角色、额外技能、局外成长、随机 Buff、结算倍率与商业系统。它们只有在改变高频操作的信息、约束或结果时，才会进入机制层。

一个实用写法是要求方案补全下面四句：

```text
玩家以前反复做：
加入规则后仍然做：
现在必须额外观察和判断：
做对以后会留下：
```

写不出第三、第四句的候选，不宜进入完整方案阶段。

## 对候选进行一次完整检查

以“蛇身加工弹药”为例：高频操作仍是转向和吞食；玩家新增观察是场上武器、组件类型与当前身体顺序；吞食组件会改变以后所有弹药，吞食武器则产生一次加工结果；身体变长提高火力，也提高移动和尾部保护压力；玩家可以学习选择路线、安排顺序和调整尾向。

这份检查支持它进入原型，但没有证明体验成立。原型还要观察加工过程是否可读、顺序差异是否足够明显、尾部参与是否增加技巧而不是操作负担。机制筛选的结论应写为“值得验证哪些主张”，而不是“这个方案已经创新且好玩”。

相反，如果候选是“贪吃蛇吃到红色道具后攻击力提高 20%”，操作、观察和局面没有发生结构变化。即使加入大量 Buff，也更接近内容扩充。

## 机制候选评分卡

每项只写证据，不急于打总分：

```text
影响的高频动作：
新增观察信息：
新增的两个合理选择：
当前选择留下的状态：
玩家可以学习的能力：
删除后损失什么：
十秒高潮怎样由玩家准备：
最可能证伪它的测试：
```

## 创新强度不是越高越好

陌生规则会增加教学成本和实现风险。短周期项目通常更适合保留熟悉输入，只改变一个持续可见的结果或约束。创新评价应与可理解性、反馈质量和学习空间一起判断，不能用“以前没见过”覆盖操作笨拙的问题。
